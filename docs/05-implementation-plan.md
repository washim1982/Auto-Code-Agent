# Implementation Plan

Twelve milestones. Each is independently demoable — that is the sequencing constraint, because an agent framework that only works at the end is an agent framework you can't debug. Estimates assume one experienced developer; treat them as relative weights, not commitments.

**Total: 83 working days** (4+8+7+7+5+9+6+7+4+7+13+6). A genuinely useful, shippable slice lands at
**M3 (~day 22)**: open a repo, browse it, chat with your local models about it, with tool calls and
fenced results. Autonomous execution starts at M4.

---

## M0 — Spine `4d`

Nothing agentic. The substrate everything else assumes.

**Tasks**
- pnpm workspace, TS project references, `tsup` builds, Vitest, ESLint with an import-boundary rule (front-ends may not import `core`).
- `@aca/protocol`: Zod schemas for `TaskSpec`, `PlanNode`, `Event`, `ToolCall`, `Approval`, RPC method types. Zero runtime deps.
- SQLite bootstrap: `better-sqlite3`, WAL, versioned migrations, `sqlite-vec` load.
- Event log: `append(event)`, `fold(runId)`, `subscribe(runId)`. Zod-validate every payload on write.
- Config: layered defaults → `~/.aca/config.json` → per-workspace `.aca/config.json` → env → flags. `keytar` for secrets.
- Workspace-scoped storage from day one — a global registry plus one `state.db` per workspace. Retrofitting this later is a migration you do not want.
- Structured logging with automatic secret redaction.

**Files** `packages/protocol/src/{task,plan,event,tool,approval,rpc}.ts` · `packages/core/src/{db/{client,migrations},events/{log,fold},config,logging}.ts`

**Done when** `pnpm test` green; an event appended in one process is observed by a subscriber in another; folding 10k events into run state takes <50 ms.

## M1 — Model layer `8d`

The riskiest external surface, so it goes early. Build it standalone, verify against real servers.

**Tasks**
- `ModelProvider` interface + `ModelCapabilities` + normalized `ChatChunk` stream.
- Adapters: **Ollama** (`/api/chat`, `/api/tags`, `/api/show`, `/api/ps`, tools, `format` schema, `think`, `keep_alive`) · **LM Studio** (`/v1/chat/completions` + `/api/v0/models` for load state and TTL) · **llama.cpp** (attach: `/props`,`/health`,`/slots`; managed: spawn `llama-server`; GBNF grammar path) · **Cloud** (Anthropic w/ prompt caching, `openai-compat` covering OpenAI/OpenRouter/Groq/DeepSeek, Google).
- Zod → JSON Schema → GBNF compiler; `generateStructured()` with strategy selection + repair loop.
- Tool-call shim for `tools: 'shim' | 'none'`.
- Probe suite + `model_scorecards` persistence.
- Residency manager: global load mutex, VRAM accounting, LRU eviction, cross-provider `snapshot()`.
- Router: hard filter → weighted rank → concurrency lease → fallback chain → circuit breaker.
- Embeddings via LM Studio `nomic-embed-text-v1.5`.

**Files** `packages/providers/src/{types,ollama/,lmstudio/,llamacpp/,cloud/,probe/,residency/,router/,structured/,shim/}`

**Done when** `aca models list` shows all four backends with real capabilities · `aca models probe --all` writes scorecards · a GBNF-constrained call cannot produce invalid JSON across 100 trials · killing Ollama mid-stream trips the breaker and the request completes on LM Studio · two concurrent requests for different large models serialize their loads.

**Risk** — llama.cpp managed mode needs a `llama-server` binary. Ship attach-mode first; managed mode gated behind a configured binary path, with a guided download in the desktop Model Manager.

## M2 — Tools and sandbox `7d`

**Tasks**
- Tool registry: Zod arg schemas, `purity: 'pure' | 'mutating' | 'irreversible'`, sandbox tier, permission scope. Built-ins: `read_file`, `write_file`, `edit_file`, `list_dir`, `glob`, `grep`, `run_command`, `git_*`, `http_get`.
- Permission matrix `(persona × tool × scope) → allow|ask|deny`, resolved at pre-flight.
- Sandbox tiers: T0 in-proc · T1 subprocess with cwd jail, env scrub, **Windows Job Object** limits, network denial · T2 Docker.
- **FS overlay** — copy-on-write, declared-writable paths only; `WriteSetViolation` on breach (F4). Checkpoint = base snapshot; rollback = discard overlay.
- **Epoch cache** (F7): `resource_epochs` bumped on committed write; cache key includes the epochs of every resource read; only `pure` tools cacheable.
- **Output guard** (F11): nonce-fenced untrusted envelope · >2KB → artifact + handle · summary generated by a **tool-less disposable-context small model**, itself wrapped.
- **Irreversible class** (F13): `git push`, deploy, publish, outbound POST → approval at execution time.

**Files** `packages/tools/src/{registry,permissions,sandbox/{t0,t1,t2,overlay,jobobject},cache/epoch,builtins/}` · `packages/core/src/guard/output-guard.ts`

**Done when** a tool writing outside its declared set fails hard · rollback restores the tree byte-identically · a mutating write invalidates the matching cache entry · a 10 MB test output becomes a pinned artifact + ≤200-token summary · injection strings in tool output never appear unfenced in a prompt.

## M3 — Workspace + chat `7d` ⭐

**The first real demo, and it ships something useful on its own.** No planner, no DAG — open a repo,
browse it, talk to your local models about it. This also de-risks M1 and M2 under real use before any
orchestration is layered on top.

**Tasks**
- **Workspace registry** — global registry at `~/.aca/workspaces.json`, per-workspace `.aca/state.db`.
  Open folder, clone from git, close, forget. All later state is workspace-scoped.
- **File tree service** — `files.tree` with git status, and the hooks (initially inert) for lock,
  write-set, and index-coverage overlays.
- **Chat threads** — `chat.create/send/subscribe`, persisted to the event log like everything else,
  so a conversation resumes after a crash and appears on the timeline.
- **Chat context assembly** — a lighter ladder than the node one: system + workspace map, conversation
  history, `@`-attached files, T3 retrieval (stub until M6), fenced tool results.
- **Read-only tool loop** in chat — `read_file`, `glob`, `grep`, `list_dir` at sandbox T1. Tool
  results go through the output guard exactly as in a run; chat is not a trust exemption.
- **Direct model selection** per thread, bypassing the router, with residency shown.
- Terminal chat UI: `aca` in a directory, `/model`, `/ws`, `@path`.

**Files** `packages/core/src/{workspace/{registry,open,clone},files/{tree,state},chat/{thread,loop,context}}` · `packages/cli/src/commands/{chat,ws}.ts`

**Done when** `aca` in a repo answers "how does auth work here?" correctly against a **local model
only**, with tool calls visible and results fenced · `/model` switches mid-conversation and the next
turn uses the new model · closing and reopening resumes the thread · `aca ws add --index` registers a
second workspace without leaking state between them.

## M4 — Single-node execution `5d`

Chat can now *answer*; this makes it *act*. Still no DAG — one task, one node, end to end.

**Tasks** Input guard (PII patterns, injection heuristics, scope check) · prompt optimizer → `TaskSpec` with acceptance criteria · pre-flight · context assembler with the priority ladder and per-call budget check (F8) · compactor · sub-agent loop (route → propose → execute → guard → observe) · basic gates (build, typecheck) · terminal `aca run` with streaming.

**Files** `packages/core/src/{guard/input-guard,prompt/optimizer,preflight/,context/{assembler,budget,compactor},agent/loop,gates/{build,typecheck}}` · `packages/cli/src/commands/run.ts`

**Done when** `aca run "add a docstring to src/foo.ts"` completes against a **local model only**, produces a correct edit, passes typecheck, and streams to the terminal.

## M5 — Planner, scheduler, DAG `9d`

**Tasks**
- Planner: schema-constrained DAG generation (GBNF/`format`) — nodes with deps, contracts, **read and write sets**, persona, acceptance criteria.
- Plan validation: acyclicity, write-set sanity, coverage of acceptance criteria, sub-task granularity.
- Approval gate; rejection reason captured as a hard replanning constraint (F16).
- Ready queue + topological execution.
- **Canonical-order lock acquisition** (F3) — deadlock-free by construction; conflict detection is path-prefix and glob aware.
- Join barrier for parallel siblings.
- Parallelism clamped by summed provider slots, not CPU count.
- Persona registry, lazy-loaded, declaring required capabilities (F17).
- Cancellation tokens at every await; SIGTERM→SIGKILL for subprocesses; checkpoint on cancel (F14).

**Files** `packages/core/src/{plan/{planner,validate,replan},scheduler/{ready-queue,locks,conflict,barrier},persona/,run/{supervisor,cancellation}}`

**Done when** a 6-node plan with 2 parallel branches executes correctly · a deliberately conflicting write set serializes rather than corrupts · a 200-run randomized scheduler fuzz produces zero deadlocks · `esc` mid-run stops within 2s and the run is resumable.

## M6 — Memory tiers `6d`

**Tasks** T2 episodic store + delta write-back · T3 indexer (tree-sitter chunking, `nomic-embed` embeddings, `sqlite-vec` + FTS5, incremental on file change) · **hybrid retrieval with reciprocal-rank fusion** · relevance write-back on nodes that pass gates · T4 lesson extraction from failures with **two-occurrence confirmation gate** and `uses`/`wins` auto-retirement below 0.5 win rate over ≥5 uses · injection of confirmed lessons at ladder position 4.

**Files** `packages/core/src/memory/{tiers,index/{chunker,embedder,store},retrieval/{hybrid,rrf},writeback,lessons/{extract,promote,retire}}`

**Done when** indexing a 5k-file repo completes in <5 min incrementally · hybrid beats vector-only on an identifier-lookup eval set · a lesson learned in run A demonstrably changes behaviour in run B · a bad lesson retires automatically.

## M7 — Gates, review, recovery `7d`

**Tasks**
- **Gate vector** (F12): build, typecheck, lint, unit, contract, secret-scan — each with severity and auto-retryability. Secret-scan hits never auto-retry.
- LLM reviewer against the node contract, routed to a **different model family than the coder**.
- Bounded review loop (F2): round cap, semantic-hash critique dedup, capped critique block, escalate on cap.
- **Error taxonomy with attempts-first classification** (F1): transient / retrieval-miss / provider-down / permission / permanent. Retry counter on the node record.
- Recovery paths: retry w/ error retained and failed code dropped · widen retrieval + re-budget · provider fallback · **park with locks retained** (F5) · rollback.
- **Cascade invalidation** (F6): rollback requeues every node whose read set intersects the rolled-back write set.
- Budget meters + stop-or-ask (F15).

**Files** `packages/core/src/{gates/{vector,build,types,lint,unit,contract,secrets},review/{critic,loop,dedup},recovery/{classifier,retry,widen,fallback,park},scheduler/rollback,budget/}`

**Done when** each error class is exercised by an injected-fault test and recovers correctly · retries provably cannot exceed the cap · a rollback requeues its readers · a budget breach pauses and asks · the reviewer rejects a deliberately contract-violating patch.

## Sequencing

```
M0 spine ─┬─ M1 models ─┬─ M3 workspace + chat ⭐ ─ M4 node ─ M5 DAG ─┬─ M7 gates ─ M8 daemon ─┬─ M9 CLI ────┐
          └─ M2 tools ──┘                                           └─ M6 memory ───────────┴─ M10 desktop┴─ M11
```

M1 and M2 are parallelizable if two people are available. M6 can run alongside M7. M9 and M10 share the protocol client and can be split cleanly.

**M3 is the pivot.** Everything before it is plumbing; everything after it is orchestration layered on a product that already works standalone. Shipping chat first means the model layer, tool sandbox, output guard, and workspace scoping all get exercised under real use before a planner can hide their bugs behind a retry.

## Risk register

| Risk | Impact | Mitigation |
|---|---|---|
| Local models unreliable at structured planning | Planner emits garbage DAGs | GBNF hard constraint + repair loop + `qualityTier: critical` routes planning to the best available model; cloud fallback |
| Single-GPU VRAM thrash under parallel DAG | 10× slowdown | Residency manager with global load mutex; parallelism clamped to provider slots; prefer-resident routing bonus |
| Windows sandbox is weaker than POSIX | Escape from T1 | Documented honestly; Job Objects + path allow-list at T1, Docker T2 mandatory for untrusted code |
| Cascade invalidation causes requeue storms | Livelock | Cap cascade depth; beyond it, fail the run and escalate rather than churn |
| Electron bundle/memory footprint | UX complaint | Renderer stays thin; heavy work in the daemon; Tauri swap is confined to `packages/desktop` |
| Event log growth | Slow folds | Periodic snapshot rows; fold from latest snapshot, not from seq 0 |
| Provider API drift (Ollama/LM Studio move fast) | Adapter breakage | Contract tests per adapter run in CI against live local servers; capability probes catch silent behaviour changes |

## Testing

- **Unit** — every module, Vitest.
- **Cassette replay** — record real model responses once, replay in CI. The whole agent suite runs offline and deterministically.
- **Golden DAGs** — fixed task specs with expected plan shapes; catches planner regressions.
- **Fault injection** — one test per error class in the taxonomy.
- **Scheduler fuzz** — randomized DAGs and write sets, asserting no deadlock, no lost update, no stale cache read.
- **Injection corpus** — the security gate; runs on every PR.
- **Live smoke** — a nightly real run against Ollama + LM Studio on the dev box.
